# Laksanasoft NetHunter Kernel for Samsung Galaxy S10+ (beyond2lte)

Automated build pipeline for Kali NetHunter Kernel on Samsung Galaxy S10+ (Exynos 9820 - `beyond2lte` / `SM-G975F` / `SM-G975FD`) running LineageOS 16.0 / 17.1.

### Features Enabled:
- **System V IPC:** Full support for Kali Chroot, PostgreSQL & Metasploit Framework.
- **Wireless Subsystem:** `mac80211` & `cfg80211` packet injection & monitor mode.
- **WiFi Dongle Drivers:** Atheros (`ath9k_htc`, `carl9170`), Realtek (`rtl8187`, `rtl8xxxu`), Ralink (`rt2800usb`, `mt7601u`).
- **USB Gadget & BadUSB:** USB Keyboard & Mouse HID injection (`f_hid`), DriveDroid mass storage.
- **Bluetooth Arsenal:** USB Bluetooth dongle support & RFCOMM TTY.
